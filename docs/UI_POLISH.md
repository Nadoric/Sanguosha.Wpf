# 界面精修 · 墨漆鎏金

## 本次调整

- **整体视觉**：以深墨蓝、漆色面板、暖金描边为基底，提升文字对比度；统一圆角、渐变和层级，保留围桌式对局布局与原有立绘、卡牌。
- **选将大厅**：新增原创品牌印记、精简标题层级；武将卡片增加悬停和键盘焦点描边，说明区使用统一内嵌面板。
- **对局界面**：精修座位边框、卡牌投影和选中光晕；战报逐条分隔、增加留白，装备区与状态栏保持一致材质。
- **交互控件**：确认/取消由位图按钮改为清晰矢量样式；主次操作分色，统一悬停、按下、禁用和键盘焦点反馈。原有手牌上浮动画保留。
- **新图标「山河剑印」**：朱砂墨漆底、金色八角印框、交叉双剑与山形印记。应用ICO包含16/24/32/48/64/128/256像素；16–32像素使用简化山形版本以保证识别。标题栏和大厅使用512像素PNG。
- **可维护性**：公共画刷、控件样式集中到 `Themes/InkGold.xaml`；图标生成器为 `tools/Generate-AppIcon.py`（Python 3 + Pillow），可复现，不依赖网络和字体。

## 不变的内容

没有修改规则引擎、AI、存档、音频、皮肤逻辑或任何C#文件。31个视图/内容模板名称、102处Binding及52处事件关联均与原版一致（样式模板内部名称随样式集中化迁移/替换）。官网下载的立绘、卡牌、音频等文件保持原样；旧官网图标改名归档，其来源清单与核验工具同步更新。

## Windows运行前后检查

1. 本包是完整源码，不含bin/obj/artifacts，请在新目录解压，不覆盖原项目。
2. Windows开发需要 .NET 10 SDK；源码运行：`dotnet run --project src/Sanguosha.Desktop`。只安装运行时不能编译源码。
3. Linux无法启动WPF，因此**尚未实际运行新界面或生成新版WPF截图**。`docs/screenshots`保留的是旧版截图，并非本次效果图。
4. 在Windows上检查100%/150%/200%缩放、最大化/还原、八人对局、手牌滚动、选将/衣橱/战报及各弹窗。字体使用系统微软雅黑、楷体/宋体回退，无需另装字体。
5. 可运行原项目的 `--verify-ui` / `--verify-skins` / `--verify-effects` / `--verify-audio` 检查运行期绑定、交互与渲染，具体命令见README。
6. 重新编译后若资源管理器或固定任务栏仍显示旧图标，先关闭旧程序、解除固定再固定新EXE；Windows可能缓存图标。

原官网下载ICO仅归档到 `Assets/Official/Icon/official-original.ico`；新 `app.ico` 的路径及项目引用保持兼容。
