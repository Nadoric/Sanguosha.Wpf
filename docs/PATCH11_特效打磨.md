# patch11 · 开战/击杀特效继续打磨

## 改进
- 使用官方图集的实际序列帧，而不是只放一张字图：七档大字/电光和开战扫光，共 **207 帧、8 组序列**。裁切恢复原图集旋转和透明裁边偏移，保留数字帧号间隔；原始下载 URL、大小、SHA-256 和派生图集来源均有记录。
- 开战原始 Laya 1.6 骨骼头部可直接读出 **2000ms** 动画时长；现在采用 2 秒主时间轴，双刀合拢后金字落定，再扫光/淡出。
- 击杀横幅不再抢在阵亡台词之前播放：**阵亡语音完成 → 对应击杀原音 MediaOpened → 对应官方字帧/横幅同时开始**。横幅时长跟随实际音频 NaturalDuration，静音、音效关闭、文件缺失或解码失败时有无声视觉释放路径。
- 修复等待阵亡台词时跳过按钮提前消失的问题；等待状态也可跳过。已跳过/切换对局的迟到音频回调不会复活横幅。多杀保持逐名配对，结果面板不会吞掉最后一击。
- 横幅改为透明渐隐边缘，减轻遮挡并移除大面积实时模糊；大字电光与称号分层。序列帧用独立离散 24Hz 键帧时钟，不以 60Hz 重绘同一帧；其他移动/渐隐仍由 WPF Storyboard 负责。
- 位图在后台最多两个解码器加载、冻结后跨线程；共享图集裁切，不反复解码单帧。预热开战/首破，在阵亡语音播放期间预取对应档位；LRU 最多保留四组解码图集，避免无限累积。动画完成/跳过/换局时仍移除时钟和可视元素。
- 座位与特效共用逻辑坐标，标题栏的 44 像素偏移只计算一次。提供并验证 2–8 人座位布局、不重叠和窗口/DPI 单次变换；当前游戏模式仍是原来的 4/5/8 人及四人 2V2，没有修改规则或新增模式。

## 官方与重现的界限
官方原图、官方原音、原像素序列帧、原始裁边/旋转数据、开战主时长均来自官方客户端公开资源；此前七档名称/身份印章不变。
**这仍不是完整移植官方 Spine/Laya 骨骼引擎。** 骨骼混合、网格变形、加色混合、原始骨骼所有层的精确轨迹暂未实现；24fps 采样、WPF 合成位置、落字/粒子/扫光启动偏移是本地重现，不能宣称与官方逐帧完全一致。
新增 8 张官方原始纹理约 5.78 MiB；8 张紧凑派生帧图约 4.02 MiB。没有生成绘画冒充官方素材。

## 复现与校验
正常覆盖补丁无需重新下载。若重建派生帧图，安装 Pillow 后运行：

```powershell
python tools/Build-OfficialEffectFrames.py
powershell -ExecutionPolicy Bypass -File tools/Verify-OfficialAssets.ps1
```

派生帧数据：`Assets/Official/EffectFrames/animations.json`；派生 SHA：同目录 `sources.json`；官方新增原图 URL/SHA：`KillEffects/sources.json`。
