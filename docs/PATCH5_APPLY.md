# patch5应用说明

这是相对于已应用patch4项目的增量，不是完整源码包，也不要求重装前几批。

1. 备份原项目与存档。
2. 将patch5.zip内容按相对路径覆盖到 `Sanguosha.Wpf` 根目录（应看到README.md、src、tests、docs）。
3. 需要删除的文件：**无**。
4. 清理旧构建缓存后重新构建、运行Verify；不要把旧输出目录当新版本运行。
5. V2/V3旧存档可读，保存后为V4，旧版本程序不支持反向读取。

本批新增29项、共84项；仍缺于吉、左慈、界关羽、界马超、界陆逊、界夏侯惇。详细名单、技能版本、素材回退及验证见EXPANSION_BATCH3.md。无bin/obj/artifacts、SDK或参考仓库文件。
