# Patch8：选将页退出、顺手牵羊/过河拆桥选牌

## 行为

### 选将页退出

- 页右上方与更换皮肤、声音、返回对局并列新增“退出游戏”，采用 InkGold 按钮样式及醒目的暖色边框。
- 首次选将尚未开始游戏、或对局已结束时直接退出。
- 对局未结束时，退出按钮、窗口关闭、Alt+F4 都经过同一个确认流程，默认选“否”，明确提醒上次保存后的进度会丢失；不会伪装成自动保存。
- 确认期间暂停 AI 计时器；取消后恢复原计时状态，保留当前对局和选择；确认退出才停止效果并释放音频。
- Esc 优先关闭皮肤/声音/玩法说明；在选将页且已有对局时返回对局。首次选将 Esc 不意外结束程序。必须选牌的结算面板不能用 Esc 取消或自动代选。

### 目标牌面板

此前引擎已经有顺手牵羊/过河拆桥的装备、判定区选择，并非全部路径都在自动选牌；但手牌只有一个“随机一张”的入口。本次把它升级为三区的逐牌选择面板：

- **手牌**：每张显示相同的中性暗色牌背及位置编号，按钮/提示/选项数据均不包含牌名、花色、点数、真实牌 ID。打开请求时洗混一次隐藏映射，同一次选择期间不会重新随机；点击哪张背面，就结算该背面绑定的实体牌。
- **装备区**：每件合法装备独立明置，可精确选择武器、防具、坐骑等，保留既有受保护装备限制。
- **判定区**：乐不思蜀、兵粮寸断、闪电分别按实际延时锦囊显示，不再把判定区所有缩略图画成乐不思蜀。徐晃等转化的兵粮寸断按标记显示、移出时清除对应标记；未选的牌不变。
- 顺手牵羊将选择的那张牌收入手牌；过河拆桥将选择的那张牌弃入弃牌堆。距离、无懈可击、技能响应、失去装备/手牌的后续触发仍走原结算链；不会绕过无懈先让人选牌。
- 面板按区域分组，可滚动；获得初始键盘焦点并限制 Tab 在面板内循环，Enter/Space 激活所聚焦选项。防止按键重复及旧请求按钮继续结算新请求。

### 共享技能路径

- 反馈/界反馈、猛进、烈刃等原本使用共享取弃牌入口的效果自动获得新面板，仍限各自规则允许的区域；例如反馈不能选择判定区。
- 突袭/界突袭先选择目标，再对每个目标逐次点选一个手牌背面；不能选装备或判定区。界突袭只选一人时仍补一张正常摸牌，选两人则不额外正常摸牌。
- 巧变摸牌阶段同样复用仅手牌面板，保留至多两名不同目标的限制。
- AI 不等待人类选牌窗口，继续原来的自动策略；手牌专用技能的 AI 分支也会正常处理失牌后的结算。
- 保留旧 `ChooseTargetCard(Hand)` 显式随机选择接口的兼容性，但桌面玩家按钮始终提交所点击的背面位置。临时请求不写入存档，未修改存档格式。

## Windows 覆盖与验收

1. 关闭旧游戏，将补丁按目录覆盖到含 `Sanguosha.slnx` 的源码根目录；无需删除任何文件。
2. 运行 `Run.cmd` 或 `dotnet run --project src\Sanguosha.Desktop -c Release`。如使用 `artifacts\app` 的发布版，先重跑 `Publish.ps1`。
3. 首次选将可直接退出；进行中打开选将后点退出，应出现默认“否”的确认框，取消后仍能返回原对局。
4. 使用顺手牵羊/过河拆桥，完成可能的无懈询问后，在三区面板选择背面或具体公开牌；检查仅该牌被获得/弃置。再试反馈、两目标突袭及巧变。
5. 可选 Windows 原生自动检查：

```bat
dotnet run --project src\Sanguosha.Desktop -c Release -- --verify-ui artifacts\verify-ui-patch8
```

退出确认在上述自动验证模式中跳过，以免自动验证结束时被模态窗口阻塞；正常启动不跳过。

分发只含相对 patch7 的变更，无新增官网素材，无需移动原 Assets、删除存档或清除皮肤偏好。删除列表：无。
